# humaniser - убери AI-измы

Скилл для Claude Code: финальная антиклише-зачистка текста. Находит нейросетевые паттерны (ложная глубина, фальшивая близость, пустые связки, канцелярит, рубленые фразы, длинные тире, шаблонные призывы) и переписывает их в живую человеческую речь, ничего не выдумывая.

**Форк** [theivansergeev/humaniser](https://github.com/theivansergeev/humaniser) с добавленными **стилевыми регистрами**: та же зачистка приводит текст к разной целевой точке — от делового-корпоративного до разговорно-экспертного.

## Что добавлено в форке

Каталог [`styles/`](styles/) — регистры переписывания:

| Регистр | Для чего |
|---|---|
| `business-corporate` | КП, отчёты, реестры рисков, паспорта систем, письма контрагентам |
| `technical-doc` | README, инструкции, регламенты, runbook, описания API |
| `plain-informative` | объясняющие статьи, справки, обучающие материалы |
| `conversational-expert` | посты, рассылки, сценарии видео, блог (поведение оригинала, по умолчанию) |
| `marketing-promo` | лендинги, офферы, рекламные тексты |

Каждый регистр задаёт тон, синтаксис, лексику, **свой дополнительный чёрный список** и — что важнее — перечень **отключённых** правил базового навыка. Без этого деловой отчёт после зачистки получал разговорные заходы вида «Знаете, бывает так…» и становился хуже исходника.

Ключевое дополнение в `business-corporate` — запрет конструкции противопоставления через «а» («это не X, а Y», «не потому, что X, а потому что Y»). Это устойчивый маркер ИИ-текста в русских деловых документах: конструкция создаёт видимость мысли, которой в предложении нет.

## Установка

Нужен установленный [Claude Code](https://docs.claude.com/claude-code) и `git`. Выполни блок под свою систему.

**macOS / Linux** (Терминал):
```bash
mkdir -p ~/.claude/skills
git clone https://github.com/starlingnic/humaniser ~/.claude/skills/humaniser
```

**Windows** (PowerShell):
```powershell
New-Item -ItemType Directory -Force "$HOME\.claude\skills" | Out-Null
git clone https://github.com/starlingnic/humaniser "$HOME\.claude\skills\humaniser"
```

Нет `git`? Поставь: macOS - `xcode-select --install`; Windows - [git-scm.com/download/win](https://git-scm.com/download/win) (или `winget install Git.Git`)

Перезапусти Claude Code - скилл подхватится сам.

## Как пользоваться

Скажи Claude любую из фраз:
- «Прогони этот текст через humaniser»
- «Убери нейросетевые клише / AI-паттерны»
- «Сделай текст более человечным»
- «Причеши стиль»

С регистром:
- «Прогони через humaniser в деловом-корпоративном стиле»
- «humaniser, регистр technical-doc»
- «Причеши, но сухо и по делу — это пойдёт заказчику»

Регистр можно не называть: скилл определит его по типу документа. Если не определит — возьмёт `conversational-expert` и скажет об этом в выводе.

Опционально: если у тебя есть файл с профилем своего голоса, скилл подстроит правки под него. Профиль голоса и регистр работают вместе: регистр задаёт жанр, профиль — индивидуальные особенности речи.

## Как добавить свой регистр

Скопировать любой файл из `styles/`, поменять разделы, положить рядом под именем `<имя>.md`. Регистрировать нигде не нужно — скилл читает каталог и подхватывает файл по имени. Подробнее — в [`styles/README.md`](styles/README.md).
